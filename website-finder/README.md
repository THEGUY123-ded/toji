# Website Finder

A lightweight static app that recommends useful websites based on what you want to do.

## Features

- Gradient, glass-style interface based on the supplied mockup
- Search box with example searches
- Curated website recommendations with short explanations
- Direct links to each recommended site
- Google fallback search for queries without curated matches
- Responsive layout for desktop and mobile
- No backend, API key, or build step required

## Run locally

Open `index.html` in a browser.

## GitHub Pages

The repository includes a GitHub Actions workflow that deploys the `website-finder` folder to GitHub Pages. Enable **Settings → Pages → Source → GitHub Actions** for the repository if Pages is not already enabled.

The existing repository root is left untouched; the app lives in `website-finder/`.
